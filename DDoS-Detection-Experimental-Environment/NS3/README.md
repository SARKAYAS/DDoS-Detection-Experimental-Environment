# NS-3 Experimental Environment

This directory contains the files related to the **NS-3 experimental environment** used in the study entitled **“Testbed Selection in Network Security: An Empirical Comparison of Simulator (NS-3) and Emulator (GNS3) Under DDoS Attack Scenarios.”**

The NS-3 environment was used to conduct DDoS attack scenarios and generate attack traffic. This directory provides the files related to the installation and configuration of the NS-3 environment.

## Directory Structure

```text
NS3/
├── code/
└── README.md
```

## 1. NS-3 Environment Setup

The `code/` directory contains the installation and environment setup commands used to conduct the experiments in the NS-3 environment.

This directory provides the commands used during the installation of the NS-3 environment and the preparation of the environment in which the experiments were conducted.

The setup commands include the necessary steps for preparing the NS-3 experimental environment used in the study.

## 2. File Purpose

| Directory | Contents |
|---|---|
| `code/` | Commands used to install and prepare the NS-3 environment |

## Reproducibility

The setup files provided in this directory are intended to facilitate the examination and reproduction of the NS-3 experimental environment used in the study.
